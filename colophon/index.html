Colophon

This website was made with pure CSS and HTML. I use VSCode to write out my code, iTerm to manage my files, and Dreamhost to host them on the web. If I want to change something I simply edit the file itself and re-upload it. Design-wise, I look to Prof. Dr. style for ease of maintenance.
This site does not track your data in any way. There are no site metrics because I don't care about that sort of thing. You can find and fork the Github repository for this website here.
